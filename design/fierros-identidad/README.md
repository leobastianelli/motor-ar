# Fierros

Identidad visual para un sitio argentino de automovilismo.

## Dirección final

Se desarrolló la dirección Torre. El símbolo es una F construida con bloques separados que recuerdan las filas de una torre de tiempos. El logotipo está dibujado como curvas y toma de Archivo su proporción compacta, sus contraformas abiertas y sus números de taller.

## Archivos principales

- `logo-horizontal.svg`: versión principal sobre fondos claros.
- `logo-positivo.svg`: copia nombrada de la versión positiva.
- `logo-negativo.svg`: versión preparada sobre tinta.
- `logo-monocromo.svg`: versión de una tinta.
- `logo-simbolo.svg`: símbolo de 32 × 32.
- `icon.svg`: favicon con viewBox 32 × 32.
- `apple-icon.png`: 180 × 180.
- `icon-192.png` e `icon-512.png`: iconos de aplicación.
- `icon-maskable-512.png`: versión maskable con el símbolo dentro del área segura central del 60 %.
- `opengraph-image.png`: imagen social de 1200 × 630.
- `avatar.png`: avatar de 1080 × 1080, preparado para recorte circular.
- `guia-de-uso.svg`: guía breve de aplicación.

## Next.js

La carpeta `src/app` contiene `icon.svg`, `apple-icon.png` y `opengraph-image.png`. Se puede copiar directamente dentro del proyecto.

## Tipografía

El logotipo final no depende de una fuente instalada: todas sus letras son paths. Las piezas informativas usan Archivo SemiBold, incluida en `fonts` bajo licencia SIL Open Font License 1.1.

## Nota

Los nombres de categorías aparecen sólo como códigos editoriales. No se usaron logos oficiales ni formas copiadas de organismos o marcas.
